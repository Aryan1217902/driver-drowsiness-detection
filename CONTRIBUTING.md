# Contributing to Driver Drowsiness Detection

Thank you for your interest in contributing to this project.

## Development Guidelines

* Keep changes focused on a specific feature or bug fix.
* Follow the existing Python and JavaScript coding conventions.
* Add or update tests when changing application behavior.
* Update the README when introducing user-facing features or changing setup instructions.
* Do not commit virtual environments, credentials, personal configuration files, or generated artifacts.

## Development Workflow

1. Create a feature branch.
2. Implement and test your changes.
3. Review the changes before committing.
4. Commit with a descriptive message.
5. Push the branch to GitHub.
6. Open a Pull Request for review.
